# Project Skills

Skills are concise, project-specific operating guides. They complement — never
replace — official language, framework and SDK documentation.

## Principle

Xcode, SwiftUI, NestJS, Prisma and game engines evolve independently. A skill
therefore records durable project decisions, integration boundaries and review
checklists, then directs an agent to the official documentation for
version-sensitive APIs.
